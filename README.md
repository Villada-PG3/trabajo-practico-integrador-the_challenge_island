## Instalación
Para instalar este proyecto corre en tu terminal
### Crear y activar un entorno virtual

**Linux / macOS:**
```bash
python -m venv venv
source venv/bin/activate
```
 
### Clonar el Repositorio e Instalar las dependencias
```bash
git clone https://github.com/tu-usuario/challenge-island.git
cd challenge-island
pip install -r requirements.txt
```
